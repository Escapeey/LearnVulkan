# 学习问答记录（QA）

这里记录我在学习过程中提出的问题，以及 Claude 的解答。按章节组织，方便以后回顾。

> **性质**：这是「学生提问 + 老师解答」的记录，和 `docs/`（备课讲义、自检题）互补。
> `docs/` 是**课前备好的内容**，`qa/` 是**实际学习中冒出来的疑问**——往往比讲义更贴合真实卡点。

## 目录

| 文件 | 内容 |
|---|---|
| [`tooling.md`](tooling.md) | 构建 / 运行工具：`build.ps1` vs `run.ps1` |
| [`d2.md`](d2.md) | D2 概念问答：实例、验证层、调试信使、`pNext` 等 |
| [`d3.md`](d3.md) | D3 概念问答：物理设备 / 逻辑设备 / 队列族 / `std::optional` 等 |

## 约定

- 每个问题一个 `##` 标题，格式：`## N. 问题（关键词）`，下面附「问题」和「解答」。
- 关键结论用 **「一句话总结」** 收尾。
- 内容随学习进度持续补充：每个单元一个文件，或一个文件里加一节。
